# 🚀 Sprint DAY 1 -- Salesforce Developer Bridge Program

Welcome to **Sprint DAY 1** of my Salesforce Developer Bridge Program
journey.

This sprint focuses on learning the fundamentals of Salesforce
development by implementing a **Hospital OPD Management System**. The
work includes Salesforce Data Modeling, Apex Programming, SOQL Queries,
Apex Triggers, and Lightning Web Components (LWC).

------------------------------------------------------------------------

## 📌 Scenario

**Hospital OPD Management System**

The project demonstrates how Salesforce can be used to manage hospital
patient appointments by creating custom objects, defining relationships,
querying data, implementing business logic, and building a simple
Lightning Web Component.

------------------------------------------------------------------------

# 🎯 Sprint Objectives

-   Learn Salesforce Data Modeling
-   Create Custom Objects and Custom Fields
-   Implement Object Relationships
-   Understand Apex Programming Basics
-   Practice SOQL Queries
-   Build an Apex Trigger with a Handler Class
-   Develop and Deploy a Lightning Web Component (LWC)

------------------------------------------------------------------------

# ✅ Tasks Completed

## 🏥 Task 1 -- Data Modeling & Object Relationships

-   Created \*\*Patient\_\_c\*\* and \*\*Appointment\_\_c\*\* custom
    objects.
-   Added required custom fields.
-   Configured a Lookup Relationship between Patient and Appointment.
-   Built the Hospital OPD data model.

------------------------------------------------------------------------

## 💻 Task 2 -- Apex Basics

-   Learned Apex syntax.
-   Declared variables.
-   Executed Apex code using Execute Anonymous.
-   Verified output using Debug Logs.

------------------------------------------------------------------------

## 🔍 Task 3 -- SOQL Queries

Executed multiple SOQL queries including:

-   Basic SELECT
-   WHERE Clause
-   ORDER BY
-   LIMIT
-   Child-to-Parent Relationship Query
-   Aggregate Query using COUNT()

------------------------------------------------------------------------

## ⚡ Task 4 -- Apex Trigger

Implemented an Apex Trigger and Trigger Handler Class to:

-   Prevent duplicate appointments.
-   Validate records before insertion.
-   Display custom error messages using `addError()`.

------------------------------------------------------------------------

## 🎨 Task 5 -- Lightning Web Component (LWC)

-   Created a Salesforce DX Project.
-   Generated an LWC component.
-   Updated HTML, JavaScript, and Metadata files.
-   Deployed the component using Salesforce CLI.
-   Added the component to a Lightning App Page.
-   Successfully activated the page.
