## 📖 Overview

This sprint focuses on building the **frontend** of the Placement
Management System using **Lightning Web Components (LWC)**. The
objective was to understand the LWC architecture, create and deploy a
component, implement data binding, handle user interactions, and build a
simple interactive dashboard.

------------------------------------------------------------------------

## 🎯 Objectives

-   Understand Lightning Web Components (LWC)
-   Learn the three-file LWC structure
-   Create and deploy an LWC using Salesforce CLI
-   Implement data binding
-   Handle button click events
-   Manage component state
-   Build a basic Placement Portal dashboard
